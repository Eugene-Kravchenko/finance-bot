# Telegram-бот для дневника состояния

Google не используется. Бот работает самостоятельно, хранит отметки в SQLite и по команде формирует Excel.

## Что умеет

- спрашивает о состоянии в 10:00, 16:00 и 22:00 по Москве;
- собирает настроение, энергию и тревогу по шкале 1–10;
- записывает сон, приём назначенных лекарств, побочные эффекты и комментарий;
- при очень низком настроении отдельно проверяет непосредственную безопасность;
- `/report` — средние показатели за 7 дней;
- `/export` — вся история в Excel;
- `/pause` и `/resume` — управление напоминаниями;
- `/delete_my_data` — полное удаление данных участницы.
- `/id` — показывает ID чата для настройки администратора.

Бот не ставит диагнозы и не меняет назначения врача.

## Перед запуском

Старый токен был опубликован в переписке. Его нужно отозвать в BotFather командой `/revoke` и создать новый.

## Быстрый запуск на компьютере

1. Установите Python 3.12.
2. Создайте окружение и установите зависимости:

   ```bash
   python -m venv .venv
   .venv/bin/pip install -r requirements.txt
   ```

3. Скопируйте `.env.example` в `.env` и вставьте новый токен.
4. Запустите:

   ```bash
   set -a
   . ./.env
   set +a
   .venv/bin/python bot.py
   ```

Пока терминал открыт, бот работает.

## Постоянный запуск через Docker

```bash
cp .env.example .env
# Вставьте новый BOT_TOKEN в .env
docker compose up -d --build
```

Для круглосуточной работы проект можно разместить на любом сервисе, который запускает Docker-контейнер. Для сохранения истории необходимо подключить постоянный том к `/app/data`.

## Как начинает работу участница

1. Открывает бота и нажимает `/start`.
2. Читает уведомление о хранении данных.
3. Нажимает «Согласна».
4. Делает первую отметку через `/checkin`.

По умолчанию отчёты доступны только самой участнице. Если нужно, чтобы их видел ещё один
человек, он сначала узнаёт свой ID командой `/id`, после чего ID задаётся в `ADMIN_CHAT_ID`.
Бот заранее сообщает участнице о такой возможности и начинает хранить данные только после
её явного согласия.

Никому не передавайте файл базы `data/mood.sqlite3`: он содержит чувствительные данные о здоровье.
